# Maptelo Lite 0.1.5

Nagrywanie programów Java obciąża program znacznie mniej. Wersja zastępuje wydanie testowe
0.1.5rc1 i zawiera wszystkie jego poprawki.

## Programy Java

- **Mniej pytań do programu.** Każde pytanie nagrywarki obsługuje wątek okien programu Java.
  Nagrywarka nie opisuje już elementu, gdy zdarzenie mówi tylko, że ekran się zmienia
  (przebudowa listy, zmiana stanu, nazwy lub wartości). Miejsce elementu, którego dotyczy
  czynność, ustala w jednym przejściu zamiast dwóch, a odczytując ekran, pomija listę działań
  elementów, której mapa nie używa. Na programie testowym zbudowanym jak Oracle Forms
  (32-bitowa Java 8) te same czynności to 36 tys. pytań zamiast 57 tys. w wersji testowej
  0.1.5rc1, a przy wyborze daty w kalendarzu o dwie trzecie mniej.
- **Zminimalizowane okno nie jest odczytywane**, na przykład gdy w trakcie nagrania kopiujesz
  dane z Excela.
- **Jedno kliknięcie to jeden krok.** Kliknięcie, które program zgłosił z opóźnieniem po
  przebudowie ekranu (kalendarz), nie jest już zapisywane dwa razy.
- **Komórka tabeli kliknięta przed wpisaniem wartości.** Nagrywarka zapisuje kolumnę komórki,
  którą wskazała tabela, a nie pierwszą kolumnę o tej samej wartości. Dwuklik otwierający edycję
  komórki jest częścią wpisu, także gdy przed edycją dwie kolumny wiersza mają tę samą wartość.
- **Dwuklik na liście wartości, która zamyka się razem z nim**, jest zapisywany jako dwuklik,
  także gdy okno listy zniknęło, zanim program zgłosił drugie kliknięcie. Następny krok jest
  wtedy odczytywany dopiero po wstawieniu wybranej wartości do formularza.
- **Połączenie z Javą w osobnym procesie**, zamykanym po każdym nagraniu, także po błędzie.
- **Dziennik obciążenia.** Plik `maptelo-lite.log` w folderze danych zapisuje liczbę elementów
  i czas każdego odczytu ekranu oraz liczbę zdarzeń programu. Zawiera wyłącznie liczby, bez
  tytułów okien i treści ekranu, więc można go przekazać do analizy, gdy program zwalnia.

## Mapa

- Powtórne otwarcie tej samej listy wartości nie przejmuje wcześniejszego wyboru.
- Okna otwarte obok siebie i potwierdzenie „Tak” na końcu procesu są rozpoznawane poprawnie.
- Przycisk OK listy wartości jest krokiem tylko wtedy, gdy lista pozostaje otwarta.

## Zakładka „Gotowość”

- Nie pokazuje już wskazówek pełnej wersji Maptelo: o naprawach AI przy skrypcie proxy i o
  uruchamianiu procesów. Lite nie korzysta z AI, a jego przeglądarka używa ustawień proxy
  Windows. Przy błędnych zasadach IT komunikat mówi, że do czasu poprawki nie są stosowane
  ustawienia przeglądarki z tych zasad.

## Usuwanie nagrań

- Nagrywarka zamyka swoje pliki także po błędzie.
- Gdy Windows zgłasza, że plik jest chwilowo używany (kody 32, 33, 124, 1224, na przykład
  w trakcie skanowania przez program antywirusowy), usunięcie jest ponawiane. Jeżeli plik nadal
  jest zajęty, komunikat wskazuje, co zamknąć.

## Ograniczenia

Działania na rzeczywistym Oracle Forms jeszcze nie potwierdzono. Program testowy jest zbudowany
podobnie, ale nie odtwarza liczby elementów i zdarzeń takiego systemu. Jeżeli program Java zwalnia
podczas nagrywania, plik `maptelo-lite.log` pokaże, który odczyt go obciąża.

## Instalacja

Dotychczasowe procesy i nagrania pozostają bez zmian. Instalator aktualizuje program w tym samym
folderze; wersję przenośną rozpakuj do nowego folderu. Sumy SHA-256 są w pliku `SHA256SUMS.txt`.

## English

Recording Java programs puts far less load on the program. This release replaces the 0.1.5rc1
test release and includes all of its fixes.

**Java programs.** Every question the recorder asks is handled by the Java program's window
thread. The recorder no longer describes an element when an event only says that the screen is
changing (a list rebuilt, a state, name or value changed). It finds the element of a person's
action in one climb instead of two, and reads screens without the elements' action lists, which
the map does not use. On a test program built like Oracle Forms (32-bit Java 8) the same
actions took 36 thousand questions instead of 57 thousand in the 0.1.5rc1 test release, two
thirds fewer when picking a date in the calendar. Minimized windows are not read (for example
while you copy data from Excel). A click that the program reported late, after rebuilding the
screen (a calendar), is no longer recorded twice. A table cell clicked before a value is typed
into it gets the column the table named, not the first column showing the same value, and the
double click that opens the cell's editor is part of the typing. A double click on a list of
values that closes with it is recorded as a double click even when the list's window was gone
before the program reported the second click, so the next step is read only after the chosen
value is in the form. The Java connection runs in a separate process, closed after every
recording, also after an error. The `maptelo-lite.log` file in the data folder records the size
and duration of every screen read and the number of the program's events: numbers only, without
window titles or screen content, so it can be shared for analysis when a program slows down.

**Map.** Opening the same list of values again does not take over the earlier choice; windows
opened side by side and a final “Yes” confirmation are recognised correctly; the OK button of a
list of values is a step only when the list stays open.

**Readiness tab.** It no longer shows the full Maptelo's hints about AI repairs behind a proxy
script or about running processes: Lite uses no AI and its browser follows the Windows proxy
settings. With a broken IT policy the message says that the policy's browser settings do not
apply until it is fixed.

**Deleting recordings.** The recorder closes its files after an error too. When Windows reports
a file as temporarily in use (codes 32, 33, 124, 1224, for example during an antivirus scan), the
deletion is retried; if the file stays in use, the message says what to close.

**Limitations.** Real Oracle Forms has not been confirmed yet. The test program is built in a
similar way but does not reproduce the number of elements and events of such a system. If a Java
program slows down while being recorded, `maptelo-lite.log` shows which read is the load.

Existing processes and recordings are kept. The installer updates the program in the same
folder; extract the portable version into a new folder. SHA-256 checksums are in
`SHA256SUMS.txt`.
