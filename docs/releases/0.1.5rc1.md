# Maptelo Lite 0.1.5rc1 — wydanie testowe

Ta wersja służy do sprawdzenia poprawek nagrywania programów Java i zwalniania plików po błędzie. Nie jest wydaniem stabilnym.

## Zmiany

- Nagrywarka zamyka pliki i własne połączenie z Javą także po błędzie rozpoczęcia, odczytu lub zakończenia nagrania.
- Połączenie z Javą działa w osobnym procesie pomocniczym, zamykanym po nagraniu również przy zgodnej bitowości bibliotek.
- Opis kontrolki jest odczytywany po powrocie z natywnego callbacku, a nie w trakcie odbierania zdarzenia Javy.
- Zminimalizowane formularze nie są odczytywane, a tekst ukrytych kontrolek jest pomijany przed jego pobraniem.
- Komunikat usuwania wyjaśnia, kiedy Windows zgłasza używanie plików.

## Sprawdzenie i ograniczenia

Sprawdzono gotową paczkę: nagrywanie testowej aplikacji na 32-bitowej Javie 8u472, okna nad oknami, minimalizację, kolejne nagrania oraz zakończenie procesów pomocniczych. Sprawdzono też utworzenie mapy, anulowanie usuwania i usunięcie nagrania przyciskiem w aplikacji. Przeszło 248 testów głównego projektu oraz 151 testów eksportu Lite.

**Nie potwierdzono naprawy zawieszania rzeczywistego Oracle EBS.** Testowa aplikacja nie odtworzyła tej awarii. Nie odtworzono również dokładnego błędu Windows 1224 zgłoszonego przy usuwaniu.

**Znany problem kalendarza:** jego zrzut może być pominięty, a kliknięcie zapisane podwójnie lub z odwróconą kolejnością czasów. Wpływ zmienionej obsługi zdarzeń na ten problem pozostaje do sprawdzenia.

## Pobranie

Plik `Maptelo-Lite-0.1.5rc1-windows.zip` zawiera sprawdzoną lokalnie paczkę dla Windows oraz Python x64 i x86. To ten sam ZIP, który przeszedł powyższe próby; nie jest przebudowany przez GitHub Actions. W tym wydaniu udostępniana jest wersja przenośna, bez instalatora.

Zamknij poprzednie Maptelo Lite, rozpakuj ZIP do osobnego folderu i uruchom `Maptelo Lite.cmd`. Zachowaj dotychczasowy folder z nagraniami. Suma SHA-256 jest w dołączonym pliku `.zip.sha256`.

## English

This is a test release for Java recording and file cleanup after recording failures. It is not a stable release.

The recorder now closes its files and owned Java connection on failures, runs that connection in a separate helper process, describes Java events after their native callbacks return, and skips minimized forms and unnecessary reads of hidden controls.

The packaged application was checked with 32-bit Java 8u472, nested windows, minimize/restore, consecutive recordings and helper shutdown. Creating a map, cancelling deletion and deleting a recording through the application were also checked. There were 248 passing main-project tests and 151 passing Lite-export tests.

**A fix for real Oracle EBS freezing has not been confirmed.** The exact Windows deletion error 1224 was not reproduced. **Calendar screenshots may be missing and a calendar click may be duplicated or have reversed timestamps.** The effect of the callback changes on this issue remains unconfirmed.

The ZIP is the locally built and tested portable package, with both x64 and x86 Python runtimes. It was not rebuilt by GitHub Actions. Close the previous Lite, extract this package into a separate folder and run `Maptelo Lite.cmd`. Keep the existing recordings folder. The `.zip.sha256` attachment contains the checksum.
